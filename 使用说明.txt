开拓轶事 · 本地运行说明
========================================

【一键启动】
双击「启动游戏.bat」。
- 若提示未检测到 Node.js，请先安装 Node.js 20 LTS 或更高版本：https://nodejs.org/
- 首次启动会自动安装依赖（需要联网，可能几分钟）。
- 之后每次双击即可直接开玩，浏览器会自动打开。

【开始游戏】
地址为 http://localhost:5173 。
若浏览器没有自动打开，请手动在地址栏输入该地址。
进入游戏后，打开「设置」，填入你自己的模型 API（Base URL / API Key / 模型名），即可开始游玩。

【存档与数据】
- 游玩存档保存在本目录下的 save\ 文件夹中（纯本地，不会上传）。
  清理浏览器缓存不会丢档；重新双击脚本即可从 save\ 读取。
- API 配置、界面设置目前仍保存在浏览器本地（IndexedDB），不在 save\ 里。
  换电脑或清理浏览器数据前，请在游戏内做好设置备份/重新填写。

【停止服务】
关闭这个启动窗口即可停止本地服务。

【常见问题】
- 端口 5173 被占用：先关闭占用该端口的程序，再重新双击脚本。
  如果坚持用别的端口，可在命令行运行：
    node node_modules\vite\bin\vite.js --port 另一个端口 --strictPort --open
- 依赖安装失败：检查网络后重新双击脚本。
- 想换一份存档：整个 save\ 文件夹复制走即可，别的机器放回同位置即可继续。
